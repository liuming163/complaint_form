腾讯文犀的 Cookie 比较特殊（用 token 鉴权，非普通 Cookie）， 请点击此处获取方法
  1. 浏览器打开并登录 腾讯文犀投诉平台
  2. 登录成功后按 F12 打开开发者工具，切到 Console（控制台） 面板
  3. 把下面这段代码粘贴进去回车执行：
⚠️ 代码含 async/await，请确保控制台允许执行（Chrome 默认允许）。执行后等待片刻，结果含 subjectGroup 字段说明自动获取成功。
(async () => {
  const token = localStorage.getItem('infringement_token');
  const sid = sessionStorage.getItem('sessionId');
  const uid = localStorage.getItem('uid');
  const h = {Authorization: token, sessionId: sid, uid, Accept: 'application/json'};
  let sg = null;
  try {
    const r = await fetch('/api/v1/account/subject/auth/0/details', {headers: h});
    const d = await r.json();
    if (d.code === 0 && d.data?.group?.id) {
      const g = d.data.group;
      sg = {isAgency:1, isTemp:0, agencyType:801,
            name:g.name, identityType:null,
            identityNum:g.orgCode, contactNo:g.contactNumber,
            email:g.email, contactName:g.contactName||g.name,
            subjectType:g.subjectType, id:g.id, orgType:g.orgType};
    }
  } catch(e) {}
  return JSON.stringify({
    token,
    tokenExpired: localStorage.getItem('infringement_token_expired'),
    loginType: localStorage.getItem('infringement_login_type'),
    uid, sessionId: sid,
    ...(sg ? {subjectGroup: sg} : {_note: 'subjectGroup 未能自动获取'})
  }, null, 2);
})()
将控制台返回的整段结果（含大括号）复制粘贴到下方 Cookie 栏即可。
